# AI Text Detector

Detect whether text is **human-written** or **AI-generated** using a standalone RoBERTa model with 10-level analysis.

## Model Details

- **Architecture**: RoBERTa-base (roberta-base)
- **Training Data**: 123,653 samples
  - 50,000 human-written texts (Wikipedia, Reddit, web sources)
  - 58,570 AI-generated texts (GPT-4, Claude, Gemini, Llama, and other models)
  - 15,083 humanized AI texts (processed through various paraphrasers)
- **Test Accuracy**: 99.18%
- **F1 Score**: 99.31%
- **Precision**: 98.75%
- **Recall**: 99.88%

## Features

- **Standalone Detection**: No external API dependencies - fully standalone using trained transformer model
- **10-Level Analysis System**: Supplementary detection insights using:
  - Statistical fingerprinting
  - Syntactic patterns
  - N-gram entropy
  - Lexical diversity
  - Named entity analysis
  - Temporal reference detection
- **Text Humanizer**: Integrated Ateeqq/Text-Rewriter-Paraphraser model for text humanization

## Classes

1. **Human-Written** - Text written by humans
2. **AI-Generated** - Text generated by AI models

## Usage

Simply paste your text into the input box and click "Analyze Text" to detect the origin of the text.

## Environment Variables

Set the following environment variables for model download from iDrive e2:
- `E2_ACCESS_KEY` - iDrive e2 access key
- `E2_SECRET_KEY` - iDrive e2 secret key

## Training

The model was trained on Google Colab with a T4 GPU for approximately 1 hour and 10 minutes on 123,653 samples.
